Gerar Etiquetas para Impressão

Marque os estilos/volumes que você precisa agora. Cada etiqueta sai pronta em JPEG, no tamanho 100mm x 70mm, com QR code + dados da Alfa — é só baixar (ou copiar a imagem) e colar no BYLabel.

*A lista de ingredientes vem padrão como "Água, Malte, Lúpulo e levedura" — confira antes de imprimir estilos com fruta, vinho ou outro insumo adicional.
